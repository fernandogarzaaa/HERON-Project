Before you start

Heron is a research preview. It can read and change files in your folder, run commands, and use the accounts you connect. Read what that means for you, then accept to continue.

Sandbox is on

Commands and CLI models run inside the macOS sandbox. They can read your working folder, and nothing outside it unless you allow it.

Sandbox is off

The macOS sandbox didn't start, so Heron won't run shell commands or CLI models. You can still accept this notice. Settings › Permissions shows the cause.
