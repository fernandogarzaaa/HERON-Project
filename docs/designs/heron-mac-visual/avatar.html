The avatar

One state value drives it, set from the event stream. Each state differs in colour and badge as well as motion, so it still reads with Reduce Motion on. Animations play here unless Reduce Motion is on.

Themes

A theme tints the window, sidebar and surfaces. Each has a light and a dark set, and all text passes WCAG AA on every surface.

Accent colours

Light and dark value of each. The accent marks selection, primary buttons and the avatar. Gold is kept for “waiting for you” and violet for outside content, so no accent uses them.
