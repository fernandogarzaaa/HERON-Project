Local-first personal AI agent

An agent that works on your computer, not someone else’s.

Heron keeps your notes, calendar, email and tasks in one place, remembers what you tell it, runs reminders and recurring jobs while it is open, and by default asks before it changes anything. Its memory and activity log stay in a folder on your computer, and your keys go to the macOS Keychain or Windows Credential Manager.

Install

Three steps, no account, no cloud to sign up for.

  1. 1
    Download

    Pick your system above. The beta is not notarized or code-signed, so macOS may need right-click, Open on first launch, and Windows may need More info, Run anyway.

  2. 2
    Open it

    macOS: drag Heron into Applications. Windows: run the installer, or unzip the portable build and run Heron.exe. Linux: extract the tarball and run ./install.sh inside it.

  3. 3
    Tell it about you

    Onboarding gets to know you, looks around your computer with your say-so, and connects notes, a calendar and email, read-only.

Why Heron

How it behaves on your computer.

Local by default

No account, no server, no telemetry. Memory, tasks and the activity log live in one folder on your computer. What you ask goes to the AI model you pick, and that model can run on your machine too, with Ollama or LM Studio.

Bring a subscription or a key

Heron can run through a CLI you already log into, such as Claude Code, Codex, Cursor or Copilot, so the plan you pay for does the thinking, and it never reads the CLI’s login. Some CLIs (OpenCode, Gemini, Qwen) use their own keys or providers instead. Any OpenAI-compatible endpoint works too.

It asks first, by default

Four permission modes, from read-only to unrestricted. The default asks before it edits a file or runs a command, file changes can be undone, and every action lands in an activity log you can read. The looser modes are yours to choose.

It works on a schedule

Reminders and recurring jobs run while Heron is open, read-only unless you give a job more. A proactivity setting runs from only-when-asked, the default, to taking over small file jobs inside your folder.

From source

Heron is open source under the Apache 2.0 license. Clone it and run the command-line app. The desktop app builds with the scripts in packaging/, described in the README.

Shell
git clone https://github.com/fernandogarzaaa/HERON-Project.git
cd HERON-Project
cargo run --release --bin heron

Heron is in beta. See the GitHub repo for the README, the changelog and the source, and the releases page for every version.
