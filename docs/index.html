Heron

A local-first, private, proactive personal AI agent that runs on your own computer.

Heron is a desktop app and command-line tool. It keeps your notes, calendar, email and tasks in one place, remembers what you tell it, works while you are away, and asks before it changes anything. Your data stays on your machine, and your keys stay in your operating system’s credential store.

Download

macOS Universal app, Apple silicon and Intel (.dmg) Windows Installer (.exe) Linux Tarball with an install script (.tar.gz)

These links point at the v0.2.0 release. Checksums are in SHA256SUMS.txt on the release page.

Install

  • macOS: open the .dmg and drag Heron into Applications. The app is not code-signed yet, so macOS shows a warning on first launch.
  • Windows: run the installer, or unzip the portable build and run Heron.exe.
  • Linux: extract the tarball and run ./install.sh inside it.

Use your subscription instead of an API key

Heron can drive the AI CLIs you already pay for, such as Claude Code, Codex, OpenCode, Cursor, Grok, Gemini, Cline, Copilot, Qwen and Antigravity, instead of needing an API key. Log in with the CLI itself, set the provider in Settings or with HERON_PROVIDER, and Heron uses your subscription. Heron never sees or stores the CLI’s login.
