Local-first personal AI agent

An agent that works on your computer, not someone else’s.

Heron keeps your notes, calendar, email and tasks in one place, remembers what you tell it, works while you are away, and asks before it changes anything. Your data stays on your machine, and your keys stay in your operating system’s credential store.

Install

Three steps, no account, no cloud to sign up for.

  1. 1
    Download

    Pick your system above. The app is not code-signed yet, so macOS and Windows show a warning on first launch.

  2. 2
    Open it

    macOS: drag Heron into Applications. Windows: run the installer, or unzip the portable build and run Heron.exe. Linux: extract the tarball and run ./install.sh inside it.

  3. 3
    Tell it about you

    Onboarding gets to know you, looks around your computer with your say-so, and connects notes, a calendar and email, read-only.

Why Heron

Built to be lived with, not demoed.

Your data stays yours

Everything lives on your computer. No account, no cloud copy, no training on your notes.

Use your subscription, not an API key

Heron can drive the AI CLIs you already pay for, such as Claude Code, Codex, OpenCode, Cursor, Grok, Gemini, Cline, Copilot, Qwen and Antigravity. Log in with the CLI itself and Heron uses your subscription. It never sees or stores the login.

It asks before it changes anything

Four permission modes, approval for anything that changes state, and undo for file changes, with an activity log you can read.

It works while you are away

Tasks, reminders and recurring jobs with per-job permissions, and a proactivity dial from only-when-asked to taking over within limits.

From source

Heron is open source under the Apache 2.0 license. Clone it and run the CLI.

git clone https://github.com/fernandogarzaaa/HERON-Project.git
cd HERON-Project
cargo run --release --bin heron
