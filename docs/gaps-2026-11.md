# What Heron still does not do

Written 27 November 2026. This is the order to build in. It sits on top of
[COMPARISON.md](COMPARISON.md) and
[designs/research/personal-agents-2026-11.md](designs/research/personal-agents-2026-11.md).
Those two compared Hark, Muse, Grok Bot, Dots, Claude Duet, OpenClaw, goose,
ChatGPT desktop, and Claude desktop. This file says what is already in the
tree and what is worth writing next.

Heron will not grow a cloud machine, an account, or telemetry. The products
that "keep working with the laptop closed" do that by leaving the computer.
That is a different product. The aim here is the best local agent, not a copy
of a hosted one.

## Already in the tree

Schedules and natural-language times. MCP client and server. Markdown skills
that do not grant permissions. Memory with history, an unconfirmed queue, and
forgetting a source. File, shell, and web tools, all behind the permission
modes. A browser that reads text. Telegram, with pairing and a durable queue.
An activity log, usage limits, and the Dusk window.

## Build next, in this order

1. **Go to anything from the keyboard.** Ctrl+K / Cmd+K opens places and
   recent conversations. Landed in the command-palette change. A thread
   search and an export of one conversation are the follow-on, because the
   palette only matches the start of a title.
2. **Routines you can pause, try, and edit.** The scheduler runs jobs. The
   window can start and cancel them. It still has no pause, a dry run, or an
   edit of the steps. Dry run must be unable to send, delete, or spend.
3. **One page of every grant, with revoke.** Approvals can last for a
   conversation. There is no single place that lists them and removes one.
4. **Memory, explained.** The Memory view can add, confirm, and delete. It
   does not yet say why a fact was recalled. Say the source and the words
   that matched, and keep unconfirmed facts visually distinct.
5. **A morning note only when something is waiting.** Today already
   summarises counts. Push it once, to the desktop, and only when a person
   needs to answer. Do not add a phone app for this.

## Do not pretend these exist

Voice, a live browser you can take over, Outlook send, a virtual card, and
Discord, Slack, or WhatsApp adapters. The channel design is
[channel-gateway.md](channel-gateway.md). The only adapter that runs is
Telegram. Another adapter is a later change with its own review, not a stub
in the window.

OpenClaw's public skill registry has shipped malicious skills. Heron keeps
skills as local files the user put there, and a skill never grants a tool.
Do not add a registry that installs code on its own.
